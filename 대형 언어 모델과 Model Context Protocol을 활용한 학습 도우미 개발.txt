### 대형 언어 모델과 Model Context Protocol을 활용한 학습 도우미 시스템
## 1. 목적
나는 기숙형 고등학교에 재학중이고, 한 달에 한 번 귀가한다. 이러한 학교의 특성상 사교육의 도움을 받기 굉장히 어렵다. 이를 보완하고자 학원의 역할을 대신해 나에게 숙제를 내주고 강제성을 부여할 수 있는 학습 도우미 시스템을 개발하고자 한다. 

## 2. 기능
전체적인 레이아웃은 ChatGPT와 같은 인공지능 챗봇과 유사하다. 왼쪽 사이드바에는 채팅 목록과 새로운 채팅 추가 버튼이 존재하고, 오른쪽에 채팅창이 존재한다. 사이드바에서 폴더와 채팅을 추가하고, 채팅과 폴더의 이름을 정할 수 있다. 오른쪽 채팅창에서는 다음과 같은 활동들을 할 수 있다.
1) 학습에 사용될 학습자료(학습지 pdf, image, 유튜브 주소 등)를 올릴 수 있다.
2) 사용할 평가방식(과제, 테스트)을 정할 수 있다.
3) 평가 일정(예. 매주 화, 목)에 대해 대형 언어 모델과 논의하고 정할 수 있다.
4) 과제를 제출할 수 있다.

## 3. 개발 계획
1) 1차
- 학습자료는 학습지 image 파일 또는 pdf만 가능하다.
- 평가방식은 과제만 가능하다.
2) 2차
- 위에서 제시한 모든 기능을 포함한다.

## 4. 아키텍쳐
학습 도우미 시스템의 아키텍쳐를 의사코드로 작성해보았다. 해당 내용은 1차 개발 계획에 따른 것이다:
// 1) 채팅 시작
if (학습지, 정답지가 업로드됨 and 평가기준, 평가일정에 대한 조건이 제시됨){
	대형 언어 모델 -> 평가 일정 정하기
	대형 언어 모델 -> mcp tools를 통해 클라우드 서버에 평가일정 저장(예. 매일 어느정도의 분량을 할지, 주말에도 할지 등을 대형 언어 모델과 대화 -> 대형 언어 모델이 해당하는 날짜에 과제를 각각 배치함)
	정답지에서 정답 txt로 추출하기
}

// 2. 과제 제출
if (사용자가 과제 제출){
	대형 언어 모델 -> mcp tools를 통해 클라우드 서버에서 진행중인 과제 불러옴
	대형 언어 모델 -> mcp tools를 통해 클라우드에 저장된 학습지의 해당 페이지와 정답 txt 파일을 불러옴
	대형 언어 모델 -> mcp resource를 통해 해당 페이지와 정답 txt 파일을 불러옴
	대형 언어 모델 -> 과제 채점 및 평가
	if (90점 이상 또는 특정 '기준'에 충족){
		 대형 언어 모델 -> mcp tools로 클라우드 서버에 저장된 달성 여부를 true로 업데이트
	}
}

// 3. 질문
if (사용자 -> 대형 언어 모델에 과제 관련 질문을 함){
	대형 언어 모델 -> mcp tools를 통해 학습지 페이지 검색
	대형 언어 모델 -> mcp resource로 검색한 학습지 페이지 불러오기
	대형 언어 모델 -> 이를 바탕으로 질문에 답변
}

// 4. 마감
if (현재 시간 = 마감 시간){
	클라우드 서버 -> 해당 과제의 달성 여부 판단
	if (과제 달성 x){
		클라우드 서버 -> api를 통해 카톡으로 부모님께 해당 사실 통지
		클라우드 서버 -> api를 통해 내 계좌에서 부모님 계좌로 10000원의 벌금 송금
	}
}
