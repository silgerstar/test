대형 언어 모델과 Model Context Protocol을 활용한 학습 도우미 시스템

## 1. 프로젝트 개요

### 1.1 목적
기숙형 고등학교 재학생을 위한 AI 기반 개인 학습 관리 시스템으로, 사교육 공백을 보완하고 자기주도적 학습에 강제성과 체계성을 부여한다.

### 1.2 핵심 가치
- **접근성**: 24/7 이용 가능한 AI 튜터
- **개인화**: 학생별 맞춤형 학습 계획 및 피드백
- **책임감**: 벌금 시스템을 통한 학습 동기 부여
- **효율성**: 즉각적인 채점과 상세한 해설 제공

### 1.3 타겟 사용자
- 주 사용자: 기숙형 고등학교 재학생 (1~3학년)
- 부 사용자: 자기주도 학습을 원하는 일반 고등학생
- 예상 사용자 규모: MVP 단계 100명, 1년 내 1,000명

## 2. 핵심 기능 및 워크플로우

### 2.1 채팅 기반 학습 세션 관리
- **세션 생성**: 과목별/주제별 독립적인 채팅 세션
- **학습 컨텍스트 유지**: 각 세션에서 업로드된 자료와 진행 상황 연속성 보장
- **멀티태스킹**: 여러 과목의 과제를 동시 진행 가능
- **폴더 구조**: 과목별 세션 정리 및 검색 기능

### 2.2 학습 자료 및 과제 설정 워크플로우
```
1. 자료 업로드 → 2. AI 분석 → 3. 과제 계획 협의 → 4. 일정 확정 → 5. 과제 시작
```

### 2.3 과제 진행 및 평가 시스템
- **실시간 진행률 추적**: 채팅 상단에 진행률 바 표시
- **단계별 제출**: 문제별/페이지별 세분화된 제출 가능
- **즉시 피드백**: 제출 즉시 채점 및 해설 제공
- **재시도 관리**: 통과 기준 미달 시 재학습 유도

### 2.4 동기부여 시스템
- **벌금 제도**: 과제 미완료 시 자동 벌금 부과
- **성취 배지**: 연속 완료, 고득점 등 성과 시각화
- **학습 통계**: 주간/월간 학습 리포트 제공
- **친구 비교**: 익명화된 또래 학습 현황 비교

### 5.2 과제 제출 및 채점 프로세스
```python
async def process_submission(session_id: str, assignment_id: str, user_answers: list):
    # 1. MCP Resource로 정답 및 문제 조회
    answers = await mcp_client.read_resource(f"session://answers/{session_id}")
    materials = await mcp_client.read_resource(f"session://materials/{session_id}")
    
    # 2. Claude API로 채점 요청
    grading_prompt = f"""
    다음 수학 문제들을 채점해주세요:
    
    문제 자료: {materials['current_pages']}
    정답: {answers['current_assignment']}
    학생 답안: {user_answers}
    
    각 문제별로:
    1. 정답 여부 (O/X)
    2. 풀이 과정 평가
    3. 틀린 부분 지적
    4. 개선 방향 제시
    5. 유사 문제 추천
    
    최종 점수도 계산해주세요.
    """
    
    result = await claude_client.chat(grading_prompt)
    
    # 3. MCP Tool로 결과 저장
    await mcp_client.call_tool("grade_submission", {
        "assignment_id": assignment_id,
        "score": result['score'],
        "feedback": result['feedback'],
        "is_passed": result['score'] >= 90
    })
    
    # 4. 통과 실패 시 추가 액션
    if result['score'] < 90:
        await mcp_client.call_tool("create_remedial_assignment", {
            "original_assignment_id": assignment_id,
            "weak_areas": result['weak_areas']
        })
    
    return result
```

## 6. 기술 스택 상세

### 6.1 백엔드
- **FastAPI + SQLAlchemy**: 비동기 처리 및 ORM

- **Celery + RabbitMQ**: 백그라운드 작업 (마감 체크, 알림)
- **Minio/S3**: 자체 호스팅 객체 스토리지
- **Langchain**: LLM 오케스트레이션

### 6.2 프론트엔드
- **Next.js 14**: SSR 및 최적화
- **Zustand**: 상태 관리
- **React Query**: 서버 상태 동기화
- **Framer Motion**: 애니메이션
- **Tailwind CSS**: 스타일링
- **Recharts**: 데이터 시각화

### 6.3 AI/ML
- **Claude 3.5 Sonnet**: 메인 LLM
- **OpenAI Whisper**: 음성 인식
- **Tesseract + EasyOCR**: 이미지 텍스트 추출
- **LangSmith**: LLM 모니터링

### 6.4 DevOps
- **Docker Swarm/K8s**: 컨테이너 오케스트레이션
- **Traefik**: 리버스 프록시 및 HTTPS
- **Prometheus + Grafana**: 모니터링
- **Sentry**: 에러 트래킹
- **GitHub Actions**: CI/CD
